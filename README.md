# 🌍 TripAdvisor Clone

A responsive **TripAdvisor Clone** built using **HTML5** and **CSS3**. This project recreates the core layout and design of the TripAdvisor homepage to practice front-end web development concepts.

## 🚀 Features

* Responsive navigation bar
* Hero section with search functionality (UI)
* Popular destinations section
* Travel categories
* Featured attractions
* Clean and responsive layout
* Footer with useful links

## 🛠️ Technologies Used

* HTML5
* CSS3
* Flexbox

## 📚 What I Learned

* Creating responsive web layouts
* Using semantic HTML elements
* Building modern UI with CSS Flexbox
* Improving page structure and styling
* Writing clean and organized code
